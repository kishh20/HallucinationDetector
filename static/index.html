Help & FAQs

Get quick answers about verification and system features

✦ How does real-time verification work?
Every question triggers parallel searches across Wikipedia, DuckDuckGo, and Google News. The assistant synthesizes a grounded response, and an independent NLI verification model cross-checks the response against the evidence.
✦ What do the confidence scores mean?
Faithful Evidence (85-100%) indicates all claims align with live web evidence. Potential Hallucination flags ungrounded assertions.
✦ How to report an issue?
Click the 👎 Thumbs Down icon under any answer. This allows you to tag why the response was inaccurate and alert our automated diagnostic auditor.
