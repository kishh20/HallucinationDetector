            ✦ How does real-time verification prevent hallucinations?
            
Every question triggers parallel searches across authoritative sources (Wikipedia API, DuckDuckGo Knowledge, Google News). The assistant synthesizes a grounded answer, and an independent Natural Language Inference (NLI) model decomposes the answer into atomic factual propositions and cross-checks every single claim against retrieved evidence.

          

          

            ✦ What does the Hallucination Confidence Score mean?
            
85%–100% (High Confidence): All propositions strictly entailed by authoritative citations.
60%–84% (Nuanced/Mixed): Context-dependent or emerging scientific consensus.
Below 60% (Potential Hallucination): Model flags unsupported assertions with exact reason tags.

          

          

            ✦ How are mathematical equations rendered?
            
The interface natively supports KaTeX typesetting. Write inline LaTeX math using \(...\) or $...$ and display equations using \[...\].

          

          

            ✦ What keyboard shortcuts are supported?
            
Enter: Send claim for verification
Shift + Enter: Newline in query input
Ctrl + ,: Open Settings modal
Esc: Close active modal or popover
